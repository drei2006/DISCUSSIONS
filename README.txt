PERSONAL PORTFOLIO WEBSITE
==========================

FILES
- index.html : page structure
- style.css  : design, responsive layout, animations
- script.js  : interactive behavior and easy personalization
- assets/portfolio-preview.png : temporary visual placeholder

HOW TO RUN
1. Extract the ZIP folder.
2. Open index.html in Chrome, Edge, or Firefox.
3. No server or installation is required.

PERSONALIZE BEFORE YOUR EVALUATION
1. Open script.js in Visual Studio Code or Notepad.
2. Change profile.name from "YOUR NAME" to your real name.
3. Change profile.email to your real email address.
4. In index.html, replace the placeholder image at assets/portfolio-preview.png with your own photo.
   Keep the filename portfolio-preview.png, or update the src in index.html.
5. Update the About Me, skills, hobbies, location, and social links to match your real details.
6. In index.html, replace the sample social links (currently #contact) with your actual profile URLs.

HCI FEATURES TO DEMONSTRATE
- Clear navigation with active-section indicator
- Responsive layout for desktop and mobile
- Hover/focus feedback on cards and buttons
- Hobby cards open a detail dialog
- Dark/light theme toggle
- Rotating fun fact button
- Scroll reveal animations and reduced-motion support
- Semantic headings, labels, keyboard-friendly controls, and visible focus behavior

NOTE
The name, email, photo, and example personal details are placeholders. Personalize them honestly before submitting.
